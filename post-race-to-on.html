The Race to O(n)

Updated 11 November 2026

Reading notes across the subquadratic-attention literature.

0:00 / 13:55
AI

Dense self-attention compares token pairs, giving quadratic arithmetic cost in sequence length at fixed head dimension. Materialising its score matrix also takes quadratic memory; IO-aware implementations can avoid that allocation. Longformer, BigBird and linear attention were already tackling this in 2020, well before hundred-thousand-token contexts became common. Longer windows made the trade-offs more expensive, rather than starting the research programme. [1⁠, 3⁠, 4⁠, 7⁠, 9⁠]

Family 1: keep the comparisons, prune them

Fixed sparse patterns compute only selected entries of the attention matrix. Longformer combines local windows with global tokens; BigBird adds random connections. BigBird proves universal approximation and Turing completeness under its assumptions, but those results do not promise equal efficiency at fixed depth. Appendix C constructs a task solvable by dense attention in a constant number of layers that requires nearly linear depth for sparse attention under standard complexity assumptions. Missing direct connections can therefore be costly even when eventual expressivity is preserved. [3⁠, 4⁠]

FlashAttention tiles exact attention into on-chip SRAM and uses an online softmax, avoiding a full score matrix in GPU memory. At fixed head dimension this brings auxiliary memory down to linear in sequence length while retaining quadratic arithmetic. Its speedup comes from reduced memory traffic. [7⁠] The cost plot below is an illustrative operation-count model, not a hardware benchmark. Its selector crossover is a chosen configuration parameter.

Family 2: learn what to prune, and pay for the learning

DeepSeek's Native Sparse Attention (NSA, February 2025) combines compressed blocks, selected blocks and a sliding window in a natively trainable design. DeepSeek Sparse Attention (DSA), introduced with V3.2-Exp in September 2025, is a separate mechanism. DSA uses the Lightning Indexer to score candidate keys and select a fine-grained sparse read. The indexer belongs to DSA, not NSA. [31⁠, 53⁠]

DSA's indexer scores query-key pairs with a cheaper scoring function than the main attention operation. Scoring all earlier keys still gives quadratic prefill work at fixed indexer dimensions, even when the selected read has a fixed budget. This matters for asymptotic scaling, but it does not cancel practical speedups at deployed lengths. The 52K crossover and 16×/190× overhead ratios quoted in SubQ's report are the vendor's estimates for particular configurations, not independent measurements or properties of NSA. [6⁠, 53⁠]

A separate routing-absorption study asks whether a trained gate improves over a frozen random gate at matched sparsity. In its controlled 31M-parameter experiment, soft joint gating gives perplexities of 48.73 and 49.83; hard top-k gating gives 71.22 and 71.24. Those measurements identify a failure mode in that setup. They do not show that every production selector, or NSA and DSA specifically, has failed to learn useful routing. Hard top-k indices have zero derivative almost everywhere, but auxiliary losses, soft routes and staged training can still train the surrounding selector. [26⁠]

Different architectures handle routing differently. Reformer uses locality-sensitive hashing; Routing Transformer updates clustering statistics; H-Transformer-1D uses a continuous hierarchical approximation. DSA uses indexer distillation and sparse-model training, and NSA supplies its own multi-branch training design. These are alternatives to test against the routing-absorption failure mode, not evidence that successful systems universally avoid hard selection or joint training. [31⁠, 33⁠, 35⁠, 36⁠, 53⁠]

Family 3: replace comparison with a running memory

A third family doesn't prune the O(T²) computation. The pairwise comparison structure is eliminated entirely. The kernel trick is to factor the similarity between a query and key as an inner product of feature maps, φ(q)ᵀφ(k), then reorder the double sum in attention so a query only ever touches one fixed-size matrix, never the T individual keys that produced it [9⁠]⁠. That matrix, W, is a running memory where each token adds an outer product of its value and feature-mapped key, and each output is one read against the current W. Training cost drops to linear in T, and inference per token becomes constant time [9⁠]⁠. This is also a description of a linear RNN. Some popular architectures are RetNet's retention mechanism with an explicit recurrent/parallel/chunkwise duality [10⁠,11⁠]⁠; RWKV's receptance-weighted recurrence, built to combine transformer-style parallel training with RNN-style constant-memory inference [12⁠,13⁠]⁠; Griffin's RG-LRU gated linear recurrence, no attention at all in the "Hawk" variant [14⁠]⁠; S4's structured state-space parameterization, made input-selective by Mamba [15⁠,16⁠,37⁠]⁠.

Mamba-2's State Space Duality result is the cleanest unification: a structured class of SSMs is exactly a form of linear attention with a semiseparable causal mask, so the same computation can be read either as a cheap recurrence or as a quadratic matrix multiply, and systems tricks transfer between the two readings [17⁠,18⁠,19⁠]⁠. That unification matters because it means this family's fixed-size state absorbing an unbounded sequence is a compression, and compression is lossy [6⁠]⁠.

Family 4: don't just accumulate, correct

Naive linear attention just writes forever: W ← W + v⊗κ, with nothing to un-write, so old associations linger and interfere with new writes to overlapping key directions [20⁠]⁠. DeltaNet asks (before writing) what the memory already predicts for the current key, and writes only the residual (one step of online gradient descent on a reconstruction loss) [20⁠,21⁠]⁠. The error-correction needs its own hardware-efficient parallelization: a chunked, WY-representation form of the delta rule (before it scales past toy sizes) [21⁠,22⁠]⁠.

DeltaNet still can't clear memory in bulk; every correction is local to one key. The lineage adds bulk forgetting one control dimension at a time. Gated DeltaNet applies a scalar decay to the whole memory before the delta-rule correction [23⁠]⁠; Kimi Delta Attention makes that decay channel-wise, so some feature subspaces are retained while others are aggressively cleared [24⁠]⁠; Gated DeltaNet-2 decouples the erase gate (which key-feature channels get removed) from the write gate (which value channels get committed), previously controlled by the same scalar [25⁠]⁠; CARVE argues Gated DeltaNet-2's gating is still over-parameterized relative to what a single hardware-friendly triangular solve supports, and restricts gating to the key axis to preserve that solve while conditioning erasure on the previous chunk's own content [38⁠]⁠. Each step is legible as one more knob on the same fast-weight object, motivated by a specific failure the previous step couldn't fix.

Family 5: prove the ceiling instead of chasing it

A fifth line of work stops optimizing architecture and asks how bad the fixed-size-state constraint fundamentally is. Jelassi et al. show theoretically that a two-layer transformer can copy strings of exponential length while any fixed-state generalized state-space model is bounded regardless of depth or training, and confirm empirically that pretrained transformers dramatically outperform pretrained SSMs at copying and retrieving context [39⁠]⁠. Zoology frames the same gap as a recall–throughput trade-off: a bounded state cannot do content-addressed recall beyond roughly its own dimension, however cleverly it's gated [27⁠,28⁠]⁠. Mimetic initialization shows that the right initialization lets Mamba copy and recall over sequences several times longer than standard init achieves, but the gap to attention narrows rather than closes [29⁠]⁠. BASED responds pragmatically, combining cheap-but-imprecise linear attention with exact softmax attention in a small sliding window, tuning the window to trace the recall–memory Pareto frontier rather than picking one point [40⁠]⁠. Log-linear attention takes the more theoretical middle path: let the number of hidden states grow logarithmically with sequence length instead of staying fixed, admitting a matmul-rich parallel form at log-linear compute cost [41⁠]⁠.

Alman and Yu establish a conditional lower bound for document-similarity tasks that transformers can implement. Under the Strong Exponential Time Hypothesis (SETH), those tasks admit no truly subquadratic algorithm in the specified regime. This is a worst-case forward-computation result, not a backward-pass theorem or an unconditional impossibility proof. [42⁠] Alman and Song separately study attention gradients: almost-linear approximation is possible in a bounded-entry regime, while a SETH-based lower bound applies beyond it. The dimensions, entry bounds and approximation tolerance are part of the theorem. [54⁠] Efficient architectures can still be useful by changing the task, accuracy target or resource trade-off.

The claim that all four properties can be had at once

Subquadratic AI's May 2026 report claims that its SSA selector is content-dependent and subquadratic including selection. The vendor reports 99.12% on 13-task RULER at 128K, 100% single-needle retrieval through 2M, and 98% retrieval at 12M after training at 1M, at a 0.13% attention budget. Its claimed 17× and 191× selector savings against DSA's Lightning Indexer are comparisons from the same report. These figures need independent replication and matched evaluation before they establish an advantage over competitors. [6⁠]

The public report omits the selector mechanism and records a trade-off between retrieval-optimised checkpoints and multi-document synthesis or contract analysis. It also describes switching the primary development signal to RULER. [6⁠] Publishing the selector, its full training cost, matched baselines and held-out task results would make the claim substantially easier to assess.

A useful diagnostic would compare SSA's trained selector with frozen and random selectors at matched sparsity. The routing-absorption study motivates that comparison; it cannot establish how an undisclosed SSA mechanism behaves. [26⁠]

An orthogonal axis: sharing across depth, not just across sequence

Every mechanism above is about sequence mixing within a layer. A separate failure mode is dilution across layers: information written at layer 3 can be hard to recover by layer 20, because each layer only sees what survived the residual stream above it. For softmax stacks, value-residual learning feeds an early layer's attention values forward into later layers to counteract this over-smoothing [46⁠,47⁠]⁠; Mixture-of-Depths lets tokens skip layers entirely via a learned router instead [48⁠,49⁠]⁠. Applying a full depth-attention operator to a linear-memory stack partially defeats the point, though (reintroduces quadratic-ish cost across depth).

Tommaso Cerruti from ETH Zürich, along with Tim Rieder, George Rowlands and Lingfeng Jin, test the DeltaNet-flavored answer. They forward a lower layer's write error into the next layer's value target (Cross-Layer Error Residuals). This doesn't beat a matched baseline, because the routed error lands in the receiver's independently-learned value space, misaligned with that layer's own geometry, competing with rather than complementing its write target [50⁠]⁠. They (i) route into the shared residual stream instead, through a zero-initialized projection so the routed contribution starts at exactly zero and the model learns how strongly to use it; and separately, (ii) route the write value rather than the write error⁠. That Cross-Layer Value Routing (CLVR) lowers final validation loss for both DeltaNet and Gated DeltaNet hosts. It cleanly establishes sharing across depth helps specifically where the naive version of it fails and that the fix is a change of injection space. The same paper's broader sweep found that a hybrid stack (one softmax layer per two linear-memory layers) beat every pure recurrent configuration tested [50⁠]⁠, echoing the MiniMax M1-to-M2 story at a much smaller scale.

The throughline

The recurring engineering questions concern different boundaries. Does content-aware routing beat a random selector? What does selection itself cost? Does cross-layer information arrive in a representation the next layer can use? The routing study, DSA and CLVR address different parts of that problem. Matched ablations and complete cost accounting are needed to connect their results; the SubQ comparison remains a vendor claim. [26⁠, 50⁠, 53⁠]

The shape of this problem looked familiar to me. The race to O(n) and continual learning asks a structurally identical question (across tasks instead of depth or token position) whether an update from a new process regime genuinely generalizes or gets absorbed and overwritten by what an earlier regime already encoded, depending on whether it's expressed in a shared geometry the receiver can actually use [51⁠,52⁠]⁠.
