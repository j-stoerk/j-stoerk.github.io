When Do AI Outputs Tip?

Updated 26 October 2026

Why this mattersThe probability of a correct answer may omit information needed to predict later errors or choose when to intervene.

Reversing “red or blue” to “blue or red” moved a model's probability of answering red by 65.3 percentage points on average. Its mean probability of an incorrect answer moved by only 1.1 points.

Across sixteen matched pairs, the shift toward blue helped when blue was correct and hurt when red was correct. The two effects largely cancelled in the average error. The probe was also too unreliable to study the loss of previously reliable behaviour, so I moved to a separately qualified retrieval task. Option-order sensitivity and forgetting need different measurements.

The broader project asks what a model carries into its next answer. Can a small description of its computation predict several future answers and the effect of a correction? Neil F. Johnson and Frank Y. Huo's Competition for attention predicts good-to-bad tipping in AI gave me a starting model: competing representations can change which output dominates as a conversation develops. [1]

Swapping one head's message

Qwen2.5-0.5B-Instruct read a source fact and answered a factual question. I kept an incorrect earlier answer in the visible conversation, then replaced one attention head's internal message with the message from a matched conversation containing the correct earlier answer.

On sixteen held-out prompts, mean error probability fell from 3.65% to 1.33%. The selected head was layer 16, head 7, using zero-based indexing; selection used separate discovery prompts. These probabilities came from a decoder restricted to two answer tokens. They are conditional model probabilities, not error frequencies from sampled conversations. [2]

The message has two components worth separating: the values carrying information and the attention weights deciding how to combine them. Replacing only the value content, while keeping the recipient's attention weights, reduced mean error to 1.26%. Replacing only the attention weights gave 3.70%. Content transfer reproduced the average rescue in this experiment; routing transfer did not.

The location of the edit also matters. In this cached decoder, temporarily patching the final layer's attention output can change the current logits without changing stored keys or values. If the same next token is forced in both runs, their later computations receive the same cache. An edit to stored values can persist because later queries can read those values again.

An attention mass for the response clock

My work on continual learning and physical modelling keeps running into a related problem: a variable can describe the present accurately while omitting information needed to update it. The fixed-prototype binary attention model gives a small example.

Let FFF be the current score margin for the incorrect answer, so its probability is σ(F/τ)\sigma(F/\tau)σ(F/τ), where τ\tauτ is the decoder temperature. The margin fixes the next-answer probability. The effective attention mass ν\nuν controls how strongly another correct output changes that margin. After jjj additional correct outputs,

Fj=νF+jβν+j.F_j = \frac{\nu F + j\beta}{\nu + j}.Fj​=ν+jνF+jβ​.

This is an exact construction for the stated simplified head, with fixed prototypes and no positions, residual path, MLP, or layer normalisation. It is not a fitted law for Qwen. The neural experiments still have to establish which parts survive the additional computation.

The time of a correction

Timing matters in the measured model too. In one recorded history, re-encoding an earlier correct “Red” as “red” before a two-answer continuation improved net success by 3.31–3.70 percentage points. Applying the corresponding normalisation only after a later accepted “Red” answer had a small negative effect on whole-continuation success.

That comparison was calculated post hoc from measured conditional probabilities. It shows why a correction needs a position in the sequence as well as a description of what it changes.

“red”, “Red”, and a longer sentence can express the same answer but leave different token histories. Semantic correctness sums the probabilities of accepted complete sequences. A ranking of one representative vector need not rank that sum.

For the later experiments I defined twelve accepted answer forms, included their end-of-answer tokens, and retained the original vocabulary normalisation. Unmeasured branches kept explicit probability bounds. Those ranges describe the contribution missing branches could make; they are not sampling confidence intervals.

Accurate prediction, a difficult baseline

A 64-number description of a structured value-cache edit, together with reference computation retained from the decoder, predicted 296 future conditional vocabulary distributions. The largest total-variation discrepancy was about 1.4×10−91.4\times10^{-9}1.4×10−9. That prediction still required the original nonlinear downstream operations: the 64 numbers describe only the edit. The CPU decoder read trained BF16 weights and computed in float64.

A state-dependent correction policy improved two-answer success by roughly 0.052–0.070 percentage points over retaining the edited cache. A simpler rule, given the current complete-answer probability, chose the same correction in every tested state. Accurate prediction had not yet demonstrated a decision advantage from remembering the intervention.

Holding the current answers fixed

The next test changes cached state while preserving declared current readouts. A content vector is distributed across 32 cached positions. Three current queries across seven reader heads impose 21 scalar constraints on that position profile. The remaining freedom can suppress current head-message changes while retaining a response at later public queries.

This uses the same geometry that makes protected subspaces useful in continual learning: a change can be invisible to one set of readouts and visible to another. The edited cache values were rounded to float32 before checking the actual output probabilities.

Four contexts combined red or blue source facts with positive or explicitly negated wording. Two opposite edits per context produced eight internal states. All eight passed the frozen matching checks:

Checks of the accepted spellings separately also found very little redistribution. Internally different states now agree on the measured current behaviour to high precision. The future semantic-error comparison is unfinished. A later head's nonzero response alone does not establish a later change in semantic correctness.

The observation used by a controller therefore needs to be specified. A head message, a vocabulary distribution, and the meaning of a complete answer preserve different information. Nick Cammarata's Goodfire essay, Neural Networks Are Already Clean, argues for examining native mechanisms with their inputs and downstream readers. Its broader claims are a working hypothesis; following the actual downstream computation is useful for these experiments. [4]

The next comparison gives one controller the edit description and others the matched initial readouts. It also includes a controller allowed to measure risk later and react then. If that reactive controller catches up, retaining internal state would need to justify its value through observation cost, latency, or an intervention window that closes before the next measurement. I have not established that advantage yet.
